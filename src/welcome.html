YouTube Playlist Search

Find the right playlist. Save the video.

Search all the playlists you own, right in YouTube’s Save menu.

YouTube access is turned off

The extension cannot work while YouTube site access is restricted. Restore access to search your playlists.

If Chrome asks, choose Allow. If access stays off, go to Chrome’s Extensions → YouTube Playlist Search → Site access and allow access On youtube.com.

Open a video → Save → type a playlist name → pick a playlist.

Sign in to the YouTube account with your playlists. This opens a fresh tab; reload any YouTube tabs you already had open so the extension can run there.

Optional shortcuts: Alt+S to save (Shorts too), Alt+P to find a playlist.

Keep it handy (optional)

Open Chrome’s Extensions puzzle menu and pin YouTube Playlist Search. Click its icon to reopen this welcome page.
