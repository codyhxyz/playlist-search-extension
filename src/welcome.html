YouTube Playlist Search

Save to the right playlist.

Search your playlists right in YouTube’s Save menu.

YouTube access is turned off

The extension cannot work while YouTube site access is restricted. Restore access to search your playlists.

Access is used only on www.youtube.com, to search and save to your playlists.

If Chrome asks, choose Allow. If access stays off, go to Chrome’s Extensions → YouTube Playlist Search → Site access and allow access to www.youtube.com.

What it can access
  • www.youtube.com only. This is the “Read and change your data on www.youtube.com” warning Chrome showed at install. It lets the extension add search to YouTube’s Save menu and save with the YouTube sign-in you already have. It doesn’t run on any other site.
  • Connects only to YouTube. Requests go only to www.youtube.com. Playlist thumbnails load from ytimg.com, YouTube’s image server. It never contacts the developer or anyone else, and has no analytics.
  • Stored on this device. Your sort order and the privacy setting for new playlists; a copy of your playlist list, kept in memory and cleared when Chrome quits; and save and day counts for the one-time review request.
  • Right-click menu. One “Save to playlist” item, shown only on YouTube pages.
